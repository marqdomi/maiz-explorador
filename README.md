# Explorador: alerta temprana de estrés hídrico en maíz de temporal (México)

Visualización interactiva de un sistema de alerta temprana para 264 municipios (2003–2025) y el pronóstico sellado de 2026.

**Abrir:** https://marqdomi.github.io/maiz-explorador/

Proyecto en los Laboratorios de Supercómputo del CIMAT (convocatoria 2026) · Marco Antonio Domínguez Becerra (KAINET).
Fuentes: SIAP, CHIRPS (UCSB-CHC), NASA POWER, MODIS (NASA), SoilGrids (ISRIC), INEGI.
